# The Second Brain Playbook — Claude × Obsidian

A single-page **field playbook** for running a self-filing second brain: you talk
in plain language, Claude reads, links, and files into plain Markdown you own.
This page is the quick reference — *what to type in each situation*, not
documentation.

## What's here

`index.html` — a self-contained, zero-dependency page (inline CSS + JS, no build
step). Open it in any browser. Every command card has a **Copy** button so you
can grab the exact line and get back to work.

## The plays

| Situation | Type this |
| --- | --- |
| End of a working session (**the only habit that matters**) | `/save` |
| You read something good | `ingest <url or file>` |
| You've hoarded a pile | `ingest all of these` |
| You're trying to remember | `what do you know about <anything>?` |
| A hard decision that matters | `/think <your hard question>` |
| You want it researched hands-off | `/autoresearch <topic>` |
| The graph feels messy | `lint the wiki` |

## The weekly rhythm — ten minutes

1. `ingest all of these` — clear the week's saved pile out of your inbox.
2. Drag the new notes out of the inbox into wherever they belong.
3. `lint the wiki` — catch orphans, dead links, and contradictions.

## Why plain Markdown

Everything is plain Markdown on your disk — no database, no rented lock-in. A
recent-context cache means each session opens already knowing what you're working
on; the `/save` habit keeps that memory current. If the tools vanished tomorrow,
you'd still own every byte.

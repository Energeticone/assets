Document crawler · Search index · AI layer

Put the index at the centre. Let every file orbit it.

AI Copernic crawls your file systems, extracts text from PDF, Office and image files, and keeps an Elasticsearch index in step with what's on disk. New files are indexed, changed files are updated, deleted files are removed.

Crawl the file system

Watch a local folder or mounted drive on a schedule. Adds, updates and deletions reach the index on every pass.

SSH · FTP

Reach remote servers

Crawl directories on remote hosts over SSH or FTP with the same settings file and the same index mapping.

REST · OCR

Upload through REST

Post a binary to the REST endpoint and get it parsed, OCR'd if it's a scan, and indexed in one call.

Installation guide

Download the distribution, unzip it, and point it at an Elasticsearch cluster. Text extraction runs on Apache Tika; the bundled clients cover Elasticsearch 7 and 6.

Third-party librariesTIFF and JPEG 2000 support depend on libraries that are not Apache-2 compatible, so they ship separately. Drop the JAI Image I/O jars into lib/ to enable them.

Quick start

Name a job, let Copernic write its settings file, then edit the folder it watches.

shell
# create the job and its settings file
bin/copernic job_name

# reindex everything from scratch, then keep watching
bin/copernic job_name --restart
~/.copernic/job_name/_settings.yaml
name: "job_name"
fs:
  url: "/path/to/docs"
  update_rate: "15m"
  ocr:
    language: "eng"
elasticsearch:
  nodes:
    - url: "http://127.0.0.1:9200"
